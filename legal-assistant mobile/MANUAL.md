## 一、产品概览

**目标用户**：普通个人与小微企业主。**主线场景**：劳动争议 + 民事领域（借贷/合同/婚姻家事/诉讼程序/房屋租赁）；其余领域兼顾，专项深度由 🧩 AI 技能包承载。

覆盖**九大法律领域**：劳动法 · 公司法 · 专利法 · 民法典 · 民事诉讼法 · 婚姻家事 · 商标与著作权 · 国际经贸合规 · 房屋租赁（v3.0 新增）。内置 **168 条法条、51 个咨询场景、45 篇讲堂 FAQ**（`node check.js` 可核对）。

**核心差异化**：可核验机制——AI 输出的每条法条引用与数字断言被程序逐条核验，按三级展示（✓✓ 原文已核对 / ✓ 来源可定位 / ⚠ 未核实），杜绝杜撰。

**App 形态**：Android WebView 壳（`com.zz333.legalassistant`，minSdk 26 / targetSdk 34，竖屏）内嵌移动适配版网页（`assets/www/`）。App 内**无本地代理**——AI 请求与联网检索经原生桥直连；图标为用户提供的獬豸设计（自适应图标，完整呈现）。

## 二、底部导航与七个视图

底部 5 个常驻 tab（咨询/分析/工具/法条/更多）+「更多」弹层收纳（合同审查/案例/讲堂）。另有全局能力：🤖 AI 设置（右上角）、🗃️ 案件工作区与 ⏳ 时效规则中心（工具页内）。

### 2.1 💬 智能咨询（主视图）

| 功能 | 逻辑说明 |
|---|---|
| 规则咨询 | 输入问题或点左侧 51 个场景卡 → `classifyDomain` 按关键词为九域打分 → `matchScenarios` 场景匹配 → 澄清问答（2-3 题，选项点选）→ 场景 `result(answers)` 生成结构化意见卡 |
| 结论前提 | 意见卡首节逐条回显「你确认的事实」（问答实录），结论依据一目了然；与事实有出入时重答或转深度分析 |
| 意见卡内容 | 结论概要 / 具体分析 / 依据法条（chips 点击跳法条页）/ 行动建议 / 计算器直达（15 场景映射）/ 继续追问 chips（按领域定制）/ 时效提示 |
| 🤖 AI 对话 | 勾选 AI 后问题转 `aiConsult`：SYSTEM_PROMPT + 预匹配资料（场景/法条/案例）+ 启用技能框架 → 流式回答 → 程序核验（三级徽标）→ 推荐追问 chips + 相关计算器 chips |
| 🎯 深度咨询 | intake 六格要素卡（当事人/时间线/金额/证据/已采取措施/诉求）——本地提取器实时点亮，AI 按缺失要素自然追问；结束时**未确认要素自动转入工作区待确认事项** |
| 渐进披露 | 结果卡「具体分析/依据法条/行动建议」默认折叠为「展开分析详情」（含条数徽标与未读蓝点）；结论前提与结论概要常显 |
| 输入区 | 双行布局（AI 开关+深度咨询工具行 / textarea+发送主行）；textarea 随内容长高（约 6 行封顶）、2000 字上限；发送键微信式（有内容才出现） |

| 功能 | 逻辑说明 |

## 三、全局能力

### 3.1 🤖 AI 模型配置
- 服务商：智谱 GLM / DeepSeek / Kimi / 通义千问 / 千帆 / OpenAI / Ollama / 自定义（OpenAI 兼容）；App 内经**原生桥直连**（无跨域问题），网页端走本地代理或直连
- 输出语言四模式（跟随提问/中文/English/中英对照，法条名保留中文+英译）
- **隐私边界**：发送前自动脱敏（身份证/手机号→占位符，默认开）· 发送前预览实际发送内容（可选）· 备份默认排除 API Key · 分项清除本机数据（对话/报告/案例/清单日历/一键全清，经 store.js 键注册表）

### 3.2 🧩 AI 技能包
用户上传 Markdown 技能包（frontmatter id/name/domains/keywords + 约定小节 `## 分析框架` / `## 证据清单：xx` / `## 文书模板：xx` / `## 术语`）扩展细分领域；四个注入点（AI 提示词/证据清单/文书模板/术语卡）；**注入 token 预算**：单技能 6000 字符、总预算 16000 字符，超出按加载顺序截断并提示；内置 2 个示例技能（建设工程/跨境电商）；安全红线：含「忽略指令/跳过核验/移除免责声明」的包拒绝导入，核验管线与免责声明不可被技能覆盖。

### 3.3 🗃️ 案件工作区
同一案件统一管理：待确认事项（增/勾/删）+ 三路自动归集（深度分析存报告库→关联报告；合规日历添加→期限提醒；案例导入→关联案例，去重）+ 判决书粘贴→**双时间线**（已发生事实时间线 + 程序期限节点：上诉 15 日/申请执行 2 年，按文书类型推算、可加入日历）+ 证据行粘贴→**规范证据目录表**（序号/名称/来源/证明目的建议）+ 导出 Word 表格 + .md 案件档案。删除案件仅解除关联不删底层数据。

### 3.4 数据与备份
备份 v3：按 store.js 键注册表导出全部数据键（对话/工作区/报告/案例/日历等，**不含 API Key**）；导入兼容 v1/v2 旧格式并保留本机 Key。

### 4.2 各模块职责与关键逻辑

| 模块 | 职责 | 关键逻辑 |
|---|---|---|
| **registry.js** | 领域注册表：九域元数据/法条/场景/FAQ/案例统一注册 | `collect(field)` 聚合全部域数据（legacy data/*.js 经 shim 并入）；`DOMAIN_SVG` 图标映射；`reviewedAt` 资料复核标记（R2026-11）；`window.LAWS/SCENARIOS/DOMAINS` 为惰性兼容层 |
| **main.js** | 路由与装配：视图切换、聊天渲染、会话管理、模块装配 | `appendResult` 生成意见卡（结论前提→概要→分析→法条→建议）；`recordMsg` 在渐进披露**之前**捕获完整 html（归集取数据源保证）；事件委托统一处理法条跳转/反馈/文书/证据/深度跳转 |
| **consult.js** | 规则咨询引擎 | `classifyDomain` 九域关键词打分 → `matchScenarios` 场景匹配 → `askNext` 澄清问答（支持 `showIf` 条件题）→ `finish` 调场景 `result(answers)`；无匹配时诚实列出擅长领域 |
| **ai.js** | AI 对话/设置/隐私/备份 | `aiChat` 单一咽喉：脱敏（身份证/手机号）→ 发送前预览 → 原生桥或代理/直连流式；`SYSTEM_PROMPT` 含追问/拒答/条件分支规则；`buildContext` 预匹配资料+技能框架注入；`buildBackup/restoreBackup` v3 格式（键注册表全量、排除密钥、兼容旧版）；`exportFeedback` 反馈清单导出 |
| **agent.js** | 深度分析工作流 + 核验引擎 | 六步工作流（资料检索→约束生成→逐条核验）；`parseCitations/verifyLocal/verifyOnline` 三级核验（tier1 定位 / tier2 与 flk 缓存原文比对）；`parseNumberClaims` 数字断言核验；`annotate` 内联 ✓✓/✓/⚠ 徽标；`renderPanel` 三级汇总报告；`AGENT_PROMPT` 硬约束（只准引用资料区/数字须有出处）；报告/时间线/归集接线 |
| **analysis.js** | 规则报告生成与渲染 | `run(q)` 离线生成结构化报告（要素/定性/法条/案例/程序/证据/风险）；`matchContext` 供 AI 侧复用；`render` 渲染报告（含技能补充清单）；案件时间线节点可视化 |
| **claims.js** | 一揽子请求与证据（v3.2 新增） | 多请求组合试算（8 类请求项勾选+计算式+合计）；证据链矩阵（每请求项所需证据勾选查缺口）；程序流程地图（劳动仲裁/民诉一审节点模板+全部入日历）；和解谈判参考卡（锚点/中间值/底线+让步考量）；配套答辩书与和解协议书模板 |

### 4.3 核验与数据流（可信机制主线）

## 五、移动端与网页端差异

| 能力 | 移动版 | 网页版 |
|---|---|---|
| AI/联网通道 | 原生桥直连（无代理依赖） | 本地代理 `/api/ai/chat` 转发，无代理降级直连 |
| 语音输入 | 已移除（用输入法自带语音） | Web Speech API |
| Word/备份导出 | 系统保存器（exportFile） | Blob 下载 |
| PDF | 原生 PrintManager | 系统打印对话框「另存为 PDF」 |
| 技能/备份导入 | 粘贴文本 | 文件选择 + 粘贴 |
| 维权材料包 zip | 逐项导出（zip 二进制暂不适用） | zip 打包下载 |
| 导航 | 底部 5 tab + 更多弹层 | 顶部 7 页签（分组） |
| 输入区 | 双行布局 + textarea 自增高 + Enter 换行 | 单行 input + Enter 发送 |

其余功能（核验三级制/渐进披露/工作区/技能包/时效中心/隐私边界/评测集）**两端完全同步**，由 sync-www 校验保证。
