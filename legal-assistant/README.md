# ⚖️ 法律咨询助手（九大部门法）

一个**零依赖、可离线运行**的法律咨询 Web 应用（自绘线性 SVG 图标系统 · 全站 emoji 图标已线性化 · 支持深色模式），覆盖九大法律领域（民法 · 民事诉讼 · 婚姻家事 · 劳动 · 公司 · 专利 · 商标与著作权 · 国际经贸合规 · 房屋租赁），提供对话式智能咨询、可核验的法律 Agent 深度分析、合同审查、法条双模式检索（本地知识库 + 国家法律法规数据库联网）、八个实用计算器 + 合规日历、案例检索与知识讲堂。领域经 `js/registry.js` 注册表配置化管理，加新领域不改业务逻辑。

另有 **Android 移动版**（WebView 壳 + 原生桥，见 `../legal-assistant mobile/` 与其 README）。

## 🚀 快速开始

### 方式一：离线模式（最简单）

直接双击 `index.html` 用浏览器打开即可。智能咨询、本地法条、计算器、内置案例全部可用。

也可构建**单文件离线版**（全部 CSS/JS 内联，双击即用、便于分发）：

```bash
node build-single.js     # 或双击 构建单文件.bat
# 产物：dist/legal-assistant-single.html
```

### 方式二：联网模式（法条库 + 案例在线检索 + AI 代理）

浏览器直连国家法律法规数据库/裁判文书网/模型 API 会被跨域策略拦截，因此提供一个**本地代理服务**（零依赖）：

```bash
node server.js      # 或 python server.py；或双击 启动.bat（自动检测 Node）
set PORT=3000 && node server.js   # 自定义端口
```

启动后访问 **http://127.0.0.1:8080**，右上角显示 `● 联网模式`；离线打开页面时只要服务在运行，刷新后也会自动探测到。

> 联网能力说明
> - 法条：flk.npc.gov.cn **2026 新版 SPA 接口**（`POST /law-search/search/list`），正文从官方 docx 提取（server.js 内置零依赖 ZIP 解析器）；上游间歇不稳定（405/系统异常/超时），前端均自动降级。
> - 案例：裁判文书网全文接口需登录且有反爬，故采用**公开搜索引擎 site: 定位**（不破解、不绕过任何访问控制）；另内置官方发布的指导性案例精读。
> - AI：经 `/api/ai/chat` 流式转发；无代理时自动直连并在失败时给出明确指引。

## 🤖 AI 模型配置

1. 点击右上角「🤖 AI 模型」→ 选择服务商（任选一家支持 OpenAI 兼容协议的厂商，部分提供免费模型；已装 Ollama 的可选本地模型）
2. 填入 API Key（[智谱开放平台](https://open.bigmodel.cn)等申请）→「测试连接」→ 保存
3. 三个用法：智能咨询页勾选「🤖 AI」自由提问；深度分析页的 AI 可核验报告；结果卡「AI 深度解读」

> 密钥仅保存在本机浏览器，不经任何第三方转发。设置弹窗支持 JSON 导出/导入。

## 🧭 加新法律领域（配置化架构）

新建 `js/domains/<id>.js` 调用注册表，再在 index.html 加一行 script 标签即可，筛选/讲堂分组/分类/推荐自动识别：

```js
window.DomainRegistry.registerDomain({
  id, name, icon, color, keywords: [...分类词],
  laws: [{id, domain, law, lawShort, article, title, tags, text, note, url?}],
  scenarios: [{id, domain, icon, name, keywords, desc, questions, result}],
  faq: [{domain, q, a, tags}], cases: [...], guiding: [...]
});
```

既有九大领域及内容量（`node check.js` 可随时核对）：劳动 39 条法条 · 公司 21 · 专利 33 · 国际经贸合规 17 · 婚姻家事 8 · 商标与著作权 9 · 民法典 16 · 民事诉讼 11 · 房屋租赁 14（共 168 条法条、51 场景、45 FAQ）。国际内容用**增量注册**（id 复用既有领域，如 patent-intl.js）。内容红线：只写稳定制度框架，清单/税率等易变信息标注「以官方最新为准」，每条附官方链接。

## ✅ 一致性校验

```bash
node check.js
```

零依赖 Node 脚本：模拟 window 按加载顺序执行全部 js，校验 index.html 结构（script 重复/文件存在/页签对应/免责声明）、领域注册表、法条/场景/FAQ/案例的字段完整性与 id 唯一性，并输出内容统计。改动后、提交前跑一遍。
