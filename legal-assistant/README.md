# ⚖️ 法律咨询助手（劳动法 · 公司法 · 专利法）

一个**零依赖、可离线运行**的法律咨询 Web 应用，聚焦劳动法、公司法、专利法三大领域，提供对话式智能咨询、法条双模式检索（本地知识库 + 国家法律法规数据库联网）、四个实用法律计算器、案例检索（中国裁判文书网 + 最高人民法院指导性案例）与知识讲堂。

## 🚀 快速开始

### 方式一：离线模式（最简单）

直接双击 `index.html` 用浏览器打开即可，无需安装任何东西。智能咨询、本地法条、计算器、内置案例全部可用。

### 方式二：联网模式（法条库 + 案例在线检索）

浏览器直连国家法律法规数据库/裁判文书网会被跨域策略拦截，因此提供了一个**本地代理服务**（零依赖）：

```bash
# Node.js（≥12）
node server.js

# 或 Python（≥3.7）
python server.py

# 自定义端口
set PORT=3000 && node server.js
```

启动后访问 **http://127.0.0.1:8080**。页面右上角会显示 `● 联网模式`；若直接双击打开页面，只要服务在运行，刷新后也会自动探测到 `127.0.0.1:8080`。

> 联网能力说明
> - 法条：`POST flk.npc.gov.cn/api/` 检索 + `/api/detail` 详情 + `wb.flk.npc.gov.cn` 正文，页面内直接查看/下载官方 Word、PDF 版本。
> - 案例：裁判文书网全文接口需登录且有反爬，故采用**公开搜索引擎 site: 定位**的方式获取可公开访问的文书/指导案例链接（不破解、不绕过任何访问控制）；另内置官方发布的指导性案例精读。
> - 若上游站点临时限流或网络不通，相关接口会返回明确错误提示，不影响离线功能。

## 🤖 AI 模型配置

1. 点击页面右上角「🤖 AI 模型」→ 选择服务商（推荐**智谱 GLM / glm-4-flash**，官方免费；已装 Ollama 的可选本地模型）
2. 填入 API Key（[智谱开放平台](https://open.bigmodel.cn)等申请）→ 「测试连接」→ 保存
3. 三个用法：**智能咨询页勾选「🤖 AI」**后自由提问（AI 结合法条/案例上下文流式回答）；分析结果卡点「**AI 深度解读**」；案情分析页点「**AI 深度分析**」

> 说明：密钥仅保存在本机浏览器，不经任何第三方转发。浏览器直连多数模型 API 会被跨域策略拦截，建议同时运行本地代理（`node server.js` / `python server.py`），AI 请求会自动经 `/api/ai/chat` 流式转发；无代理时自动尝试直连并在失败时给出明确指引。

## 🧠 咨询引擎工作原理

1. **领域分类**：对输入做三领域关键词加权投票（劳动/公司/专利），得到领域与置信度；
2. **场景匹配**：在领域内按关键词命中长度计分，选出最贴近的场景（如「被辞退」「竞业限制」「注册资本实缴」「专利被侵权」）；
3. **事实澄清**：按场景决策树逐题确认关键事实（问题支持 `showIf` 条件显示）；
4. **结构化意见**：`result(answers)` 依据答案组合动态生成分析（如 N / N+1 / 2N 的分支判断）、引用法条（可点击跳转检索页）、行动建议与时效提示。
