## 一、产品概览

「法律咨询助手」是一个**零依赖、可离线运行**的法律咨询 Web 应用（另有 Android 封装版），覆盖**九大法律领域**。

> **目标用户与主线**（v2.7 定位）：主服务**普通个人与小微企业主**，主线场景为**劳动争议 + 民事领域**（借贷/合同/婚姻家事/诉讼程序），其余领域（公司/专利/商标著作/国际经贸合规）为兼顾对象——专项深度优先由 AI 技能包（§9.1）承载。三群用户的**核验/资料/隐私内核完全共用**（§9.1–9.2），表现层按主线打磨。

| 领域 | 说明 |
|---|---|
| 劳动法 | 辞退/工资/加班/社保/年假/竞业限制/工伤/调岗 |
| 公司法 | 出资/股权/知情权/决议/清算/人格否认 |
| 专利法 | 申请/侵权/无效/职务发明/国际申请 |
| 民法典 | 婚姻继承/民间借贷/合同/侵权/隐私 |
| 房屋租赁 | 押金退还/提前退租与转租/欠租收房/维修责任/买卖不破租赁/没签合同（v3.0 新增主线领域） |
| 民事诉讼法 | 管辖/起诉/保全/执行/应诉 |
| 婚姻家事 | 反家暴保护令/抚养费/探望/彩礼 2024 新规/家务补偿 |
| 商标与著作权 | 注册/撤三/侵权惩罚性赔偿/避风港/AI 生成物 |
| 国际经贸合规 | 美国出口管制/实体清单/OFAC 制裁/301/232/337/CBAM/欧盟 AI 法案 |

**八大页面 + 更多收纳**（v3.6.0 IA 重构）：💬 智能咨询（含 AI 引导式深度咨询）· 🧭 深度分析 · 🗃️ **案件工作区（独立页签，原工具页弹层升格）** · 🧮 工具（10 计算器 + 日历）· 📚 法条检索（页签让位后移入「更多」/顶栏入口）· 📑 合同审查 · 🗂️ 案例 · 📖 讲堂。

**核心差异化**：**可核验机制**——AI 输出的每条法条引用与数字断言都被程序逐条核验，未核实内容标 ⚠️ 并可一键严格模式重生成，杜绝杜撰。

## 二、💬 智能咨询

### 2.1 规则咨询（离线可用）
1. 输入自然语言问题，或点左侧「快捷咨询」选择场景（51 个场景，按领域筛选）
2. 系统自动识别领域与场景 → 澄清式问答（2-3 题，选项点选）
3. 输出结构化意见卡：**结论前提（基于你确认的事实，逐条回显问答实录）** / **结论概要 / 具体分析 / 依据法条（可点击跳转法条页）/ 行动建议 / 时效提示**——结论所依据的事实与用户确认的出入时一目了然
4. 结果卡按钮：AI 深度解读 · 转深度核验分析 · 生成文书 · 证据清单 · **计算器直达**（按场景挂载，如被辞退→补偿金试算，点击自动切工具页+定位+部分场景预填参数）· 继续追问 · 白话术语卡 · 复制/打印/反馈

### 2.1b 空态引导与防误点（v3.2 新增）
- **空态三入口卡**：新会话欢迎语下三张引导卡（① 直接描述问题 ② 从场景开始 ③ 深度咨询），新用户第一眼知道走哪条路
- **自动隐藏防误点**：发出第一条消息后，快捷场景卡、静态推荐问题卡、入口卡一并隐藏——问商标不会再误点出劳务/公司法的推荐；新对话/清空后自动恢复

### 2.2 AI 对话（需配置 AI 模型）
- 勾选「🤖 AI」后自由提问；AI 结合法条/案例上下文流式回答，多轮记忆；完成时按**白名单轻量 Markdown 渲染**（粗体/列表/小标题/引用，先转义再重建不引入原生 HTML，v3.4.4）；**＋添加附件**（v3.4.7）：点＋号自选「图片」（1-2 张随消息发送，自动切 vision 模型如 glm-4v-flash 免费档）或「文档」（Word/表格/文本 ≤2 个，本机提取正文以【附件：名称】并入下一条 AI 消息——同走脱敏/发送前预览管线；未开 AI 时提示先开启）
- 回答后自动追加：「可以继续问我」推荐追问 chips（按领域定制 4 个）+「相关计算器」直达链接
- 轻量核验条：自动标注引用核实情况
- **失败体验（v3.4.4）**：请求 90 秒无进展自动中断（不再永久转圈）；401/402/404/429/5xx 显示人话指引而非英文报文；流中断**保留半截内容**（标注未核验）+ 错误条 + **一键重试**（三个 AI 入口统一，此前仅对话有重试）；手动停止同样保留已生成部分；流式输出「距底才跟随」，上翻历史不再被拽回
- **上下文预算与自救（v3.5.0）**：按服务商预设上下文档位自动裁剪会话记忆与系统资料（Kimi 8k 档此前数学上必溢出）；仍溢出时**历史自动减半重试**（有界收敛）而非只报错
- **AI 记忆随会话（v3.5.0）**：切换/恢复会话时按消息重建 AI 记忆——AI 不再对刚聊过的案情「失忆」；AI 回答带**「重新生成」**按钮（自动移除旧答案记录与记忆对后重问）

### 2.3 🎯 一揽子请求与证据（v3.2 新增，工具页入口）
同一案件多笔钱一次算清：8 类请求项（2N/经济补偿/代通知金/二倍工资/拖欠工资/加班费/年假 200%/社保补缴估算）勾选+参数 → 逐项计算式试算+合计；**证据链矩阵**（每请求项所需证据勾选、缺口自动汇总并转工作区待办）；清单复制/存入工作区。配套：**程序流程地图**（劳动仲裁 7 节点/民诉一审 7 节点，按已完成步数铺剩余节点、一键全部入日历）与**和解谈判参考卡**（锚点/中间值/底线+让步考量，明示不预测结果）+ 答辩书/和解协议书模板。

### 2.3b 🎯 AI 引导式深度咨询（v2.3 新增）
像律师接案一样逐项收集案情要素：

1. 点输入框旁「深度咨询」按钮（需已配置 AI 模型）
2. 描述初步问题 → AI 按缺失要素**逐项自然追问**（每次只问 1-2 个，不轰炸）
3. **案件要素卡**实时点亮六格：当事人关系 / 时间线 / 金额标的 / 证据持有 / 已采取措施 / 您的诉求（绿✓已确认 / 虚线○缺失；可收起/展开）
4. 要素齐全（或随时点「用这些信息生成可核验分析」）→ 自动汇总结构化案情（含"未覆盖要素"边界声明）→ 交深度分析生成可核验报告

> 技术说明：要素判定由**本地规则提取器**驱动（可靠、可离线核验），AI 负责自然追问——两者解耦。

### 2.4 对话管理
- 多会话历史 + 归档（「⋯」菜单：归档 / **导出 MD** / 删除，独立浮层点开即见；导出含时间戳与免责声明，v3.5.0）；**会话标题搜索**（v3.4.4）
- 语音输入（网页版 Web Speech API；移动端已移除独立语音按钮，直接用**输入法语音输入**更稳定）
- **会话自动绑定激活案件**（v3.3）：工具页激活案件后，咨询会话按首条消息自动关联到该案件（按会话 id 去重），工作区「关联会话」点击即切回对应会话并跳到咨询页——案件中心化的最后一块
- 会话数据存本机 localStorage，设置弹窗支持 JSON 备份/导入

## 三、🧭 深度分析（法律 Agent）

粘贴完整案情 → 六步可视化工作流（资料检索 → 约束生成 → 逐条核验）→ 输出**可核验分析报告**。

### 3.1 两种模式
| 模式 | 说明 |
|---|---|
| 规则报告（离线可用） | 规则引擎即时生成：要素提取（金额/时间）→ 初步定性 → 匹配法条（含原文）→ 参考案例 → **仲裁/诉讼请求参考** → 阶段化程序建议 → 证据清单 → 风险提示 |
| AI 可核验分析（需配置） | 锁定「资料区」（本地法条库 + 联网官方全文）→ AI 仅依据资料区作答 → 程序逐条核验 |

**📎 案件附件（v3.4.5）**：输入区「附件」按钮上传 **Word（.docx）/ 表格（.xlsx）/ CSV/文本**——零依赖解析器（纯 JS ZIP+inflate）在本机提取正文，以【附件：名称】定界追加进案情，随粘贴文本走同一条脱敏/核验/归档管线（单文件 ≤8MB，正文 >2 万字截断明示；旧版 .doc/.xls 二进制格式明确拒绝并指引另存）。「图片」按钮上传照片：AI 分析时**自动读图**（vision 模型，glm 预设自动换 glm-4v-flash 免费档）生成案情描述（自带「AI 读图描述，未经核验」标注），并同步登记进工作区证据目录；每案最多 3 张。

### 3.2 报告的律师实务层（v2.3 新增，v2.7/v3.1 扩展至 51 场景九域全覆盖）
规则报告在基础结构上自动注入四层专业内容（劳动 10 · 公司 7 · 民法典 6 · 民诉 4 · 家事 3 · 商标著作 2 · 租赁 6 · 专利 7 · 国际经贸 6）：

1. **争点分析（IRAC 律师思路）**：每场景 2-4 个争点，按「问题 → 法律规则 → 适用到本案 → 小结」展开
2. **对方抗辩预案（Red Team）**：对方可能的 2-4 个抗辩（如"严重违反规章制度""自动离职"）+ 我方应对 + 所需反驳证据——**v3.4 升级为反制链视图**（左轴串联 + 序号节点，抗辩→应对→所需证据成链）
3. **行动路径对比表**：和解 / 监察投诉 / 支付令 / 仲裁（劳动）等路径的**成本 / 周期 / 门槛 / 优势 / 短板 / 适合**七维对比——**v3.3 上方叠加泳道示意条**（周期档位长度 + 成本档位颜色，示意排序以详表为准）
4. **案件评估矩阵**：事实线索 / 证据自检 / 时效 三维度**定性评估**（明确免责：反映信息完备度，非胜诉率预测）——**v3.3 上方叠加信息完备度雷达**（越外圈越充分；口径不变）

### 3.3 AI 输出的可核验机制（v2.7 起为三级制）
1. 生成前：硬约束提示词——只准引用「资料区」内法条，数字断言必须有出处
2. 生成后：程序逐条核验，**按三级展示，杜绝「找到即已核实」的虚标**：
   - **① 来源可定位**：引用在本地知识库或官方来源中定位到出处（徽标 ✓）
   - **② 原文已核对**：条文文本与**官方全文本机缓存**（flk docx 提取）逐字比对一致（徽标 ✓✓）；离线未比对的明确标注「原文未比对」
   - **③ 结论支持**：数字断言（期限/比例/金额）逐项在资料区找依据；结论的语义正确性**不在程序核验范围**，面板中明确声明
   - 错误条文号单独警示：「仅定位到该法律，未定位到条文号」
3. 展示：内联 ✓✓/✓/⚠️ 三级徽标 + 三级汇总**引用核验报告** + 未核实内容**一键严格模式重新生成**
4. **⏹ 停止按钮**：AI 生成过程中可随时停止（令牌制中断，后续阶段静默退出）

### 3.4 导出与存档
- **导出 PDF / Word**：格式选择弹窗——Word(.doc) 直接下载（可编辑）；PDF 经系统打印对话框「另存为 PDF」（正文裁剪为意见书版式，矢量真 PDF）。打印动作交由文档原生程序执行
- **报告存档**：「存入报告库」保存到本机（上限 30 份）→「报告存档」弹窗回顾 / 再次导出 Word / 删除；**v3.2 起存档列表直接显示核验概览**——✓✓ 原文已核对 / ✓ 已定位 / ⚠ 未核实的条数分布 + 数字断言比（结构化 vstats 随存档持久化，旧记录回退摘要）

### 3.5 报告阅读增强与可视化（v3.1–v3.4，svgchart 原语库）
- **渐进披露**（v3.1）：深度报告 8 重区块默认折叠 + 标题可点 + 顶部目录导航（13 chips 直达并自动展开）+ **内含量徽标与未读小蓝点**（会话级，展开即消失）；打印/导出前自动全部展开
- **程序建议时序分层**（v3.2）：每步按「立即（红）/ 7 日内（橙）/ 立案前（蓝）/ 诉讼·执行（紫）」四档彩色徽章分层——时效动作的先后一眼可见
- **案件全周期 stepper**（v3.3）：程序建议头部的阶段条，节点色 = 时序分层（只表达建议推进顺序，非进度承诺）
- **风险分级着色**（v3.3）：风险提示逐条带分级标记——高=实心●红 / 中=空心○橙 / 低=小空心○灰（**形状+填充双通道，色盲可达**），悬停看分级说明
- **白话术语高亮**（v3.2）：报告正文命中的术语（55 条词表）虚线下划线，点击弹白话卡——随读随解
- **事实高亮**（v3.4）：正文中的日期/金额自动琥珀底色着色，聚焦法律文书的数字锚点（与术语高亮视觉区分、互不嵌套）
- **引用条文原文卡**（v3.4）：AI 报告中可定位的法条引用**点击就地弹出条文全文卡**（本地库原文 + 官方原文链接），未定位的引用引导到法条页检索——引用溯源不打断阅读

> 上述图形由 **`js/svgchart.js` 零依赖原语库**统一驱动（ring 圆环 / stepper 阶段条 / scale 标尺 / ladder 阶梯 / radar 雷达 / lanes 泳道），颜色全部引用 CSS 语义令牌（暗色模式自动适配），入场动效尊重系统「减少动态」设置。

## 四、📑 合同审查

粘贴合同文本 → 选择合同类型（**5 类**：劳动合同 / 通用商业合同 / 租房合同 / 借款合同 / 保密协议，v3.2 扩容）→ 规则引擎核对：**必备条款核对（逐项命中/缺失）+ 高危语句识别**（含逐条法条依据），支持离线核对与 AI 深度审查两种模式；**「上传合同」直传 docx/txt**（本机提取正文，v3.4.5）；两种审查结果均可**一键存入案件工作区（文书草稿）**（v3.4.3，未激活案件时按钮置灰并提示）。各类型高危模式示例：劳动合同押金/放弃社保/工伤概不负责；租房「押金概不退还」/单方涨租/转租免同意；借款砍头息（民法典 670）/LPR 四倍红线/复利；保密协议竞业无补偿/终身竞业/全员绑定。
